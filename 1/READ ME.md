# Калькулятор на Python

## Назначение проекта

Простой консольный калькулятор, написанный на Python без использования
сторонних библиотек. Программа выполняет базовые арифметические операции
над двумя числами и работает в интерактивном режиме: пользователь вводит
данные, получает результат и может продолжить вычисления или выйти.

Проект создан как учебный пример: в нём показаны ввод/вывод, обработка
ошибок, циклы, условные конструкции и форматирование результата.

## Какие задачи решает программа

- Выполняет арифметические операции над двумя числами:
  - `+` — сложение
  - `-` — вычитание
  - `*` — умножение
  - `/` — вещественное деление
  - `//` — целочисленное деление
  - `%` — остаток от деления
  - `^` — возведение в степень
- Принимает числа как с точкой (`3.14`), так и с запятой (`3,14`).
- Проверяет корректность ввода: если введено не число — сообщает об
  ошибке и просит повторить ввод.
- Защищает от деления на ноль: выводит понятное сообщение вместо
  аварийного завершения.
- Позволяет выйти из программы в любой момент, введя `q` на шаге
  ввода первого числа или операции.
- Корректно обрабатывает прерывание с клавиатуры (`Ctrl+C`) и конец
  ввода (`Ctrl+D` / `Ctrl+Z`) — завершается без «traceback».
- Красиво форматирует результат: убирает `.0` у целых чисел
  (`5.0` → `5`).

### Требования

- Python 3.6 или новее (используются f-строки).
- Никаких сторонних библиотек устанавливать не нужно.

### Запуск

1. Сохраните код программы в файл, например `calculator.py`.
2. Откройте терминал (командную строку) в папке с файлом.
3. Выполните:

   ```bash
   python calculator.py
