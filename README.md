# LP
Калькулятор на Python
Назначение проекта
Простой консольный калькулятор на Python без сторонних библиотек. Программа выполняет базовые арифметические операции над двумя числами и работает в интерактивном режиме.

Проект создан как учебный пример: в нём используются ввод и вывод данных, обработка ошибок, циклы, условные конструкции, функции и форматирование результата.
Возможности программы
Калькулятор поддерживает операции:
- + — сложение;
- - — вычитание;
- * — умножение;
- / — вещественное деление;
- // — целочисленное деление;
- % — остаток от деления;
- ^ — возведение в степень.
Также программа:
- принимает числа с точкой (3.14) и запятой (3,14);
- проверяет корректность ввода чисел;
- сообщает об ошибке при неизвестной операции;
- защищает от деления на ноль;
- после каждого вычисления предлагает выполнить следующую операцию;
- принимает варианты ответа да и нет (также д, н, yes, no);
- повторяет вопрос, если ответ о продолжении введён неправильно;
- позволяет выйти, введя q при вводе первого числа или операции;
- корректно завершает работу при Ctrl+C и при завершении ввода (Ctrl+D в Linux/macOS, Ctrl+Z, затем Enter в Windows);
- убирает .0 у целых результатов (5.0 отображается как 5).
Требования
- Python 3.6 или новее.
- Сторонние библиотеки не требуются.
Запуск
1. Сохраните файл программы Calkulator.py.
2. Откройте терминал в папке с файлом.
3. Выполните команду:
python Calkulator.py
Если команда python не срабатывает, попробуйте python3 Calkulator.py (Linux/macOS) или py Calkulator.py (Windows).
Пример работы
Поддерживаемые операции: +, -, *, /, //, %, ^
Для выхода введите 'q' при вводе первого числа или операции.

Введите первое число (или 'q' для выхода): 10
Введите операцию (+, -, *, /, //, %, ^): *
Введите второе число: 5
Результат: 50

Хотите выполнить ещё одну операцию? (да/нет): да

Введите первое число (или 'q' для выхода): 100
Введите операцию (+, -, *, /, //, %, ^): /
Введите второе число: 4
Результат: 25

Хотите выполнить ещё одну операцию? (да/нет): нет
Работа программы завершена.
Выполнение практической работы №2
В программу добавлена возможность выполнять несколько вычислений подряд без повторного запуска. После каждого результата пользователь выбирает, продолжать работу или завершить её.

Дополнительно обрабатываются неизвестная операция, деление на ноль, некорректный ввод чисел и неправильный ответ на вопрос о продолжении. Изменения сохранены отдельным коммитом после коммита исходной версии проекта.
